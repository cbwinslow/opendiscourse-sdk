# Development Guides

This directory contains development guides and documentation for OpenDiscourse.

## Available Guides

- **Getting Started**: Setting up the development environment
- **Architecture**: System architecture and design decisions
- **Contributing**: Guidelines for contributing to the project
- **Testing**: How to write and run tests
- **Deployment**: Deployment procedures and best practices

## Quick Start

1. Clone the repository
2. Set up your development environment following the Getting Started guide
3. Read the Architecture guide to understand the system design
4. Follow the Contributing guidelines when making changes
