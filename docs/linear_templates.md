# Linear Payload Templates

These templates define the JSON payload shapes for creating core Linear items via the API (pulses, customers, members).

## Pulses
- id: string (unique identifier within Linear) or generated by API
- name: string
- description: string
- status: string (e.g. planned, in_progress, completed)
- due_date: string (ISO date) or null
- related_issues: array of GitHub issue numbers or URLs
- labels: array of strings
- owner_id: string (Linear user or assignee)

Example
{
  "name": "Ingestion Pipeline Stabilization",
  "description": "Stabilize the ingestion pipeline, add retries, and improve monitoring.",
  "status": "in_progress",
  "due_date": "2025-12-31",
  "related_issues": ["GH-123", "GH-124"],
  "labels": ["project-v2", "ingestion"],
  "owner_id": "me@example.com"
}

## Customers
- id: string
- name: string
- contact_email: string
- account_type: string (e.g. trial, starter, pro)
- notes: string

Example
{
  "name": "OpenDiscourse Community",
  "contact_email": "ops@example.org",
  "account_type": "pro",
  "notes": "Primary external stakeholder for ingestion improvements."
}

## Members
- id: string
- name: string
- role: string
- email: string
- joined_at: string (ISO date)
- status: string (active, inactive)

Example
{
  "name": "Alex Doe",
  "role": "Data Engineer",
  "email": "alex@example.org",
  "joined_at": "2024-05-01",
  "status": "active"
}
