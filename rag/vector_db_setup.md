# Free Vector Database Setup for RAG

This project supports the following free vector databases for Retrieval Augmented Generation (RAG):

- **Redis (local, open source)**
- **Weaviate**
- **Chroma**

## Installation
Dependencies are listed in `requirements.txt`:
- `redis` (for local Redis vector search)
- `weaviate-client` (for Weaviate)
- `chromadb` (for Chroma)

## Usage
- Choose your preferred vector DB in your RAG pipeline code.
- Example scripts and integration guides will be provided in this directory.
