# README.md

Welcome to the **Multi‑Agentic Programming, Algorithms, Memory & Self‑Healing Systems** textbook repository.

This repository contains:
- A complete mini‑textbook (Markdown chapters)
- Diagrams (Mermaid files)
- Working example code in Python, TypeScript, and Go
