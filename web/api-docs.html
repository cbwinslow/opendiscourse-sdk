Welcome to the OpenDiscourse API

The OpenDiscourse API provides comprehensive access to government document analysis, semantic search, and AI-powered research capabilities. This documentation covers all available endpoints, request/response formats, and authentication methods.

🔍 Search API

Semantic and keyword search across document corpus

📁 Document Ingestion

Upload and process documents for analysis

💬 AI Chat

AI-powered question answering with sources

📋 Task Management

Create and manage analysis tasks

🔧 System Diagnostics

Monitor system health and performance

🏷️ Entity Extraction

Manage extracted entities and relationships

Authentication

Most API endpoints require authentication. You can use either:

  • API Key: Include X-API-Key header with your API key
  • JWT Token: Include Authorization: Bearer <token> header

Rate Limits

API requests are rate limited to ensure fair usage:

  • Search: 100 requests per minute
  • Upload: 10 requests per minute
  • Chat: 20 requests per minute

Response Formats

All responses are in JSON format. Successful responses include the requested data, while error responses follow a standard format with error codes and messages.
